# Sacred Threads of India – AI Cultural Heritage & Religious Traditions Reasoning Agent

## Problem Statement
Religious clothing in India is deeply tied to culture, symbolism, and tradition. Yet most people only see the surface — “what is worn” — without understanding the deeper meaning of *why*, *when*, and *how* these garments are used. This project solves that gap by creating an AI Reasoning Agent that explains the cultural, historical, and religious significance of clothing traditions across Indian religions.

## Solution Overview
Sacred Threads of India is an AI agent built on Microsoft Foundry with Foundry IQ integration. It categorizes clothing by religion, occasion, and symbolism, then explains origins, meanings, sect differences, and modern adaptations. The agent acts as a cultural intelligence platform rather than a simple clothing database.

## Architecture Diagram
Input → Reasoning Framework → Foundry IQ Retrieval → Structured Explanation → Output

## Reasoning Workflow
1. Identify religion
2. Identify clothing item
3. Identify context/occasion
4. Determine intent (history, meaning, symbolism, comparison, etc.)
5. Retrieve grounded knowledge via Foundry IQ
6. Generate structured explanation with citations

## Features

- Timeline of clothing evolution
